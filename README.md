# EcoCycle

EcoCycle adalah aplikasi mobile untuk pengelolaan limbah, marketplace produk berkelanjutan, edukasi lingkungan, dan konsultasi pertanian.

## Modul Utama

- Autentikasi akun
- Profil pengguna
- Marketplace
- Edukasi
- Konsultasi ahli
- Notifikasi
- Riwayat transaksi

## Menjalankan Aplikasi

```bash
flutter pub get
flutter run
```

## Backend

Backend berada di folder `backend` dan saat ini menangani register, login, dan data user aktif.
